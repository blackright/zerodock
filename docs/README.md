## Requirements and Historical Records

The [project constitution](../.specify/memory/constitution.md) defines governance.
Feature requirements, plans, task lists, and evidence are indexed in
[the specification register](../specs/README.md).

Historical research and measurement reports preserve what was known at that time.
They are not current installation instructions or proof that all gates pass today.
Read the current status in this documentation before interpreting an old report.

Local agent instructions and drafting templates are operational material, not public
product guides. Their approval rules are preserved, not rewritten as marketing copy.
